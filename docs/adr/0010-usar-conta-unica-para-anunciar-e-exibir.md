# ADR-0010: Usar conta única para anunciar e exibir

## Contexto
O produto serve exibidores e anunciantes. Muitos negócios fazem os dois papéis, por exemplo um bar que exibe e também anuncia. A entrevista traz o motivo do usuário: "para fortalecer a rede".

## Decisão
Uma conta única serve para anunciar e para exibir. A mesma conta acessa as áreas Anunciar e Exibir sem novo cadastro.

## Consequências
### Positivas
- Fortalece a rede, motivo dado pelo usuário.
- Cadastro único para quem exerce os dois papéis.

### Negativas e trade-offs
- O modelo de acesso precisa separar papéis (exibidor, anunciante, admin) dentro da mesma conta.
